Leonida Legend: an offline guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI — every trophy with its official name, description and grade, a guide in its own words with named sources, a 6-stage roadmap to the platinum, missable flags, filters by kind and grade, a spoiler-safe mode, and progress saved in the browser with export and import.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The guide is plain static files under `app/` — no build step, no network requests — and `main.ts` hands it in: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
