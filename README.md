Leonida Legend — an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5: cited guides in its own words, a three-stage platinum roadmap, a missable flag, and a checklist that saves in the browser and exports to a file.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `app/` with any static file server. It works with the network off: no external requests, no web fonts, no images.
